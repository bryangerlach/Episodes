To enable personalized show and anime recommendations, you need to provide a TMDB API Read Access Token in your environment configuration.

How to get a TMDB API Token:
  1. Go to The Movie Database (TMDB) and sign up for a free account.
  2. Navigate to your account Settings > API.
  3. Request an API key (Developer option is free and instant).
  4. Copy your API Read Access Token (the long JWT string starting with eyJ...).
Option 1: If using docker-compose.yml (Recommended)

Open your repository's docker-compose.yml file and paste your token inside the TMDB_ACCESS_TOKEN environment variable:

services:
  web:
    image: bryangerlach/episodes:latest
    restart: unless-stopped
    environment:
      SECRET_KEY: "%qufh2ea8!-$%_ctzw=in*d2__i#s*3_mph82!+(3m9g*!%@tt"
      CSRF_TRUSTED_ORIGINS: "http://localhost"
      TMDB_ACCESS_TOKEN: "your_long_api_read_access_token_here"
    ports:
      - "3000:3000"
    volumes: 
      - db-data:/app/db
    dns:
      - 8.8.8.8

volumes:
  db-data:

After saving your file, apply the changes by running:

docker compose down && docker compose up -d
Option 2: Manual Server Setup (Non-Docker)

If you are running the app manually on a host machine, configure the environment variable based on your operating system:

  • Windows:
    1. Press the Windows Key, search for Environment Variables, and select Edit the system environment variables.
    2. Click Environment Variables... and click New... under user or system variables.
    3. Set Variable name to TMDB_ACCESS_TOKEN and Variable value to your token. Click OK.
    4. Restart your terminal or VSCodium window.

    Alternatively, in PowerShell/CMD before running Django:

    # PowerShell
$env:TMDB_ACCESS_TOKEN="your_token_here"

:: Command Prompt (CMD)
set TMDB_ACCESS_TOKEN=your_token_here
  • Linux (Manual Shell Export): Export the variable in your shell session before starting Django: 
    export TMDB_ACCESS_TOKEN="your_token_here"
python manage.py runserver 0.0.0.0:3000

    To make it permanent, add the export line to your ~/.bashrc or ~/.zshrc file.
